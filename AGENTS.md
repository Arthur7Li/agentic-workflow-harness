# AGENTS.md

This file exists for tool compatibility (some agent tools look for
`AGENTS.md` instead of `GEMINI.md`). It is a pointer, not a duplicate source
of truth.

**Canonical operating rules for this project live in `GEMINI.md`** (created
from `GEMINI.md.template` — see `docs/harness/CUSTOMIZATION.md` if that file
doesn't exist yet in your copy of this repo). Read that file in full before
doing any work. Any agent or tool that supports `AGENTS.md` should treat
`GEMINI.md` as the authoritative rules file.
